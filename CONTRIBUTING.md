# Como Contribuir

Obrigado por contribuir com o OpenCryptoLab!

## Fluxo de trabalho
- Use **issues** para bugs e features (templates disponíveis).
- Abra PRs pequenos e objetivos, vinculando issues.
- Padrões: **Conventional Commits**, revisão obrigatória, todos os checks verdes.

## Qualidade
- Testes automatizados obrigatórios (alvo de cobertura  80%).
- Lint/estilo conforme o projeto.
- Documentação atualizada (README/Swagger/Config) no PR.

## Branches e releases
- `main`: estável.
- `feature/*`, `fix/*`: desenvolvimento.
- Releases versionadas seguem SemVer.

## Segurança
- Nunca vaze segredos. Use variáveis/config segura.
- Reporte vulnerabilidades via SECURITY.md.
