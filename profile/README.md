# OpenCryptoLab

> Infraestrutura aberta para soluções cripto seguras, observáveis e escaláveis.

## Visão
Construímos uma base modular e segura para produtos cripto, com foco em qualidade, governança e velocidade com segurança.

## Roadmap e Status
- Project v2 (Org): https://github.com/orgs/OpenCryptoLab-Org/projects/1
- Views: Board, Table e Roadmap (datas já configuradas por campo)

## Arquitetura (alto nível)
- `Services`: API (Gateway/Facades)
- `Modules`: Auth, Wallet, Marketplace, Checkout, Notify, Storage, Backoffice, Financial, Support, Engagement, Quality, Reports
- `Shared`: Domain, EventBus

## Como contribuir
- Leia o `CONTRIBUTING.md` do backend: https://github.com/wellingtonpoll/OpenCryptoLab/blob/main/CONTRIBUTING.md
- Padrões: Conventional Commits, PR com checklist, testes obrigatórios
- Issue templates: bug/feature (já disponíveis)

## Qualidade
- CI: build, testes, análise estática e qualidade
- Cobertura alvo  80%
- Revisão: mínimo 1 reviewer + todos os checks verdes

## Segurança
- Política: https://github.com/wellingtonpoll/OpenCryptoLab/blob/main/SECURITY.md
- Contato para disclosure: security@opencryptolab.org (ou abrir issue marcada como `security`)
- Práticas: segredos centralizados, rate limiting, observabilidade (logs, métricas e traces)
