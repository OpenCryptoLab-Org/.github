# Política de Segurança

Relatos de vulnerabilidades:
- E-mail: security@opencryptolab.org
- Alternativamente, abra uma issue marcada como `security` com detalhes limitados (sem PII/segredos).

SLA de resposta: **72 horas** para triagem inicial.

Boas práticas internas:
- Segredos gerenciados centralmente.
- Rate limiting na API.
- Observabilidade (logs, métricas, traces) habilitada.

Divulgação responsável: seguiremos com correções e publicação dos CVEs/avisos quando aplicável.
