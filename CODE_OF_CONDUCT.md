# Código de Conduta

Adotamos o Contributor Covenant (v2.1) como base de conduta para toda a comunidade OpenCryptoLab.

- Seja respeitoso e profissional.
- Não toleramos assédio, discriminação ou comportamento abusivo.
- Use linguagem clara e construtiva.

Relatos e denúncias podem ser enviados para: security@opencryptolab.org.

Referência: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
